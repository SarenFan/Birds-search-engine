Giải thích: Nếu không dùng Lock, 20 thread ghi đồng thời sẽ dẫn đến data corruption (dòng JSON bị xen lẫn). Mỗi Lock bảo vệ một tài nguyên khác nhau để tránh bottleneck.

**4.2. Xử lý Teencode - Thách thức đặc thù Social Listening**

Đây là phần quan trọng thứ ba. Giải thích chiến lược:
- Dictionary-based: 80+ teencode mapping
- Boundary-aware regex: chỉ thay thế từ đứng riêng, không phá hỏng URL hay hashtag
- Sort by length: thay thế từ dài trước để tránh partial match

```python

TEENCODE_DICT = {
    # Teencode phổ biến
    'ko': 'không', 'dc': 'được', 'đc': 'được',
    'mk': 'mình', 'ae': 'anh em', 'ny': 'người yêu',
    # Viết tắt chính thức
    'bhyt': 'bảo hiểm y tế', 'bhxh': 'bảo hiểm xã hội',
    'thpt': 'trung học phổ thông', 'cccd': 'căn cước công dân',
    # Voz-specific slang
    'thím': 'bạn', 'vozer': 'thành viên voz', 'thớt': 'topic',
}

# src/crawler/parser.py:282-318
def normalize_teencode(text):
    # Sort by length - longer first to avoid partial replacements
    sorted_teencode = sorted(TEENCODE_DICT.items(), 
                             key=lambda x: len(x[0]), reverse=True)
    
    for teen, standard in sorted_teencode:
        # Boundary-aware regex: NOT preceded/followed by letters
        pattern = r'(?<![letters])' + re.escape(teen) + r'(?![letters])'
        result = re.sub(pattern, standard, result, flags=re.IGNORECASE)
```

```python
    async with aiohttp.ClientSession() as session:
        response = await session.get(url)  # ✅ aiohttp hỗ trợ await
```

**Vấn đề:** `cloudscraper` (thư viện bypass Cloudflare) được xây trên `requests` — là thư viện **blocking** (đồng bộ). Không thể dùng `await` với nó:

```python
# KHÔNG THỂ làm thế này
async def fetch(url):
    response = await scraper.get(url)  # ❌ cloudscraper không hỗ trợ await
```

**Giải pháp:** Dùng **multi-threading** — mỗi thread chạy `scraper.get()` blocking riêng, nhưng 20 threads chạy song song nên vẫn nhanh:

```python
# Thread 1: scraper.get(url_1)  — đang chờ response
# Thread 2: scraper.get(url_2)  — đang chờ response  (chạy đồng thời)
# Thread 3: scraper.get(url_3)  — đang chờ response  (chạy đồng thời)
# ...
```

**Tóm lại:** Nếu dùng `aiohttp` thì bypass Cloudflare không được. Nếu dùng `cloudscraper` thì phải dùng threading thay vì async. Nhóm chọn ưu tiên bypass Cloudflare → chọn `cloudscraper` + threading.
