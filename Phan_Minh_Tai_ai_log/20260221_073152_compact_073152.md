## Vấn đề hiện tại

`doc_info` giữ **1M entries trong RAM suốt Phase 1**, mỗi entry chứa `{length, title, url}`. Ước tính:

- 1M docs x ~200 bytes/entry (title dài) = **~200MB RAM** chỉ riêng cho `doc_info`
- Cộng thêm RAM của block đang build → áp lực bộ nhớ tăng

## 3 cách tách `doc_info` ra sau

### Cách 1: Flush `doc_info` xuống đĩa cùng lúc với block

Khi flush block, **ghi kèm doc_info của block đó** thành file riêng (hoặc gộp chung). Sau khi merge xong các block, đọc lại tất cả doc_info files và gộp.

- RAM: chỉ giữ doc_info của 10K docs/block → ~2MB
- Tradeoff: thêm I/O đọc lại doc_info files

### Cách 2: Pass riêng — đọc JSONL lần 2 chỉ để lấy metadata

Phase 1 chỉ lo **indexing**, không lưu doc_info. Sau khi merge xong, đọc lại JSONL lần nữa chỉ để lấy `doc_id, len(tokens), title, url`.

- RAM: Phase 1 dùng **100% cho indexing**
- Tradeoff: đọc file JSONL 2 lần (nhưng lần 2 rất nhanh vì chỉ lấy metadata, không tính term_pos)

### Cách 3: Chỉ lưu `length` trong posting, bỏ title/url khỏi RAM

`length` tính được từ postings (tổng tf của tất cả terms trong 1 doc). `title` và `url` đọc lại từ JSONL khi cần hiển thị kết quả search (lazy load).

- RAM: **không cần doc_info ở Phase 1** 
- Tradeoff: search chậm hơn vì phải đọc JSONL khi hiển thị kết quả

## Đề xuất

**Cách 1** là cân bằng nhất — giữ logic đơn giản, RAM thấp, không cần đọc JSONL 2 lần. Flush doc_info theo block giống y hệt cách flush inverted index, rất nhất quán với tinh thần SPIMI "xử lý theo block, không giữ gì ngoài block hiện tại".

Tuy nhiên với 1M docs thực tế, **200MB cho doc_info không phải vấn đề nghiêm trọng** — máy tính hiện đại thường có 8-16GB RAM. Phần ngốn RAM nhiều nhất vẫn là **block dict** (term → postings), không phải doc_info. Nếu block_size = 10K thì block dict chỉ chiếm ~50-100MB rồi flush, nên tổng peak RAM ~300MB — vẫn chạy tốt.

     ```python
       P1: docs → blocks (index trên RAM → sort by term → flush đĩa)
       P2: n-way merge blocks (heap) → inverted index
       P3: đọc lại JSONL lấy doc metadata (tách riêng để giảm RAM)

     from tqdm import tqdm

     class InvertedIndex:
         """
         index:    term -> {'df': int, 'postings': [(doc_id, tf), ...]}
         doc_info: doc_id -> {'length': int, 'title': str, 'url': str}
         """
         def __init__(self):
             self.index = {}
             self.doc_info = {}
             self.total_docs = 0
             self.total_terms = 0
             self.avg_doc_length = 0.0

         def get_postings(self, term):
             return self.index.get(term, {}).get('postings', [])
         def get_df(self, term):
             return self.index.get(term, {}).get('df', 0)
         def get_doc_length(self, doc_id):
             return self.doc_info.get(doc_id, {}).get('length', 0)
         def get_doc_title(self, doc_id):
             return self.doc_info.get(doc_id, {}).get('title', '')
         def get_vocabulary_size(self):
             return len(self.index)
         def compute_stats(self):
             self.total_docs = len(self.doc_info)
             self.total_terms = len(self.index)
             if self.total_docs > 0:
                 self.avg_doc_length = sum(d['length'] for d in self.doc_info.values()) / self.total_docs
         def save(self, path):
             os.makedirs(os.path.dirname(path) or '.', exist_ok=True)
             with open(path, 'wb') as f:
                 pickle.dump({'index': self.index, 'doc_info': self.doc_info,
                              'total_docs': self.total_docs, 'total_terms': self.total_terms,
                              'avg_doc_length': self.avg_doc_length}, f)
         @classmethod
         def load(cls, path):
             with open(path, 'rb') as f:
                 data = pickle.load(f)

             idx.index, idx.doc_info = data['index'], data['doc_info']

             self.block_size = block_size
             self.block_dir = block_dir
         def build(self, jsonl_path, index_path='data/index/inverted_index.pkl'):
             with open(jsonl_path, 'r', encoding='utf-8') as f:
                 total = sum(1 for _ in f)
             print(f"SPIMI: {total:,} docs, block={self.block_size:,}")
             if os.path.exists(self.block_dir):
                 shutil.rmtree(self.block_dir)
             os.makedirs(self.block_dir)

             with open(jsonl_path, 'r', encoding='utf-8') as f:
                 for line in tqdm(f, total=total, desc="P1:Index"):
                     doc = json.loads(line)
                     doc_id, text = doc.get('doc_id', ''), doc.get('text_segmented', '')
                     if not text or not doc_id:
                         continue
                     for term, tf in Counter(text.split()).items():
                         block[term].append((doc_id, tf))
                     n += 1
                     if n >= self.block_size:
                         block_files.append(self._flush(block, len(block_files)))
                         block, n = defaultdict(list), 0
             if block:
                 block_files.append(self._flush(block, len(block_files)))
             # P2: MERGE
             final = self._merge(block_files)
             shutil.rmtree(self.block_dir)
             # P3: METADATA
             with open(jsonl_path, 'r', encoding='utf-8') as f:
                 for line in tqdm(f, total=total, desc="P3:Meta"):
                     doc = json.loads(line)
                     doc_id, text = doc.get('doc_id', ''), doc.get('text_segmented', '')
                     if not text or not doc_id:

                     final.doc_info[doc_id] = {
                         'length': len(text.split()),
                         'title': doc.get('thread_title', ''),
                         'url': doc.get('url', ''),
                     }
             final.compute_stats()
             final.save(index_path)
             print(f"Done: {final.total_docs:,} docs, {final.total_terms:,} terms, avgdl={final.avg_doc_length:.1f}")
             return final
         def _flush(self, block, num):
             path = os.path.join(self.block_dir, f'block_{num:04d}.pkl')
             with open(path, 'wb') as f:
                 pickle.dump(sorted(block.items()), f)
             return path
         def _merge(self, block_files):
             iters = []
             for path in block_files:
                 with open(path, 'rb') as f:
                     iters.append(iter(pickle.load(f)))
             heap = []
             for i, it in enumerate(iters):
                 item = next(it, None)
                 if item:
                     heapq.heappush(heap, (item[0], i, item[1]))
             final = InvertedIndex()
             while heap:
                 term, bi, postings = heapq.heappop(heap)
                 all_p = list(postings)
                 while heap and heap[0][0] == term:
                     _, oi, op = heapq.heappop(heap)
                     all_p.extend(op)
                     item = next(iters[oi], None)
                     if item:

                 if item:
                     heapq.heappush(heap, (item[0], bi, item[1]))
                 final.index[term] = {'df': len(all_p), 'postings': all_p}
             return final
     ```


Nếu muốn gộp thành 1 class cũng được, nhưng sẽ khó dùng hơn vì BM25 chỉ cần data mà phải import cả algorithm.
